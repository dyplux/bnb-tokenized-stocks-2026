# Dyplux project context

Last verified: 2026-10-05. Scope: this public Tokenized Stocks repository and its reusable lessons. Canonical owner/source: [STATUS](STATUS.md), [frozen claims](docs/submission/frozen-claims-2026-10-05.md) and [knowledge index](docs/knowledge/README.md). Supersedes: none. Status: CURRENT.

Dyplux publishes evidence-led crypto research and builds tools that make a user action safer or clearer. This repository is the October 11 BNB Tokenized Stocks entry. [Set and Earn](docs/knowledge/programs/set-and-earn-2026.md) is a separate November 5 campaign with a separate repository and qualification rules; Bell is another separate project.

The frozen product is a deterministic pre-signing execution-safety layer for autonomous tokenized-equity agents. It returns `ALLOW`, `DENY` or `NEED_HUMAN` with reason codes and a verifiable receipt. The observed purchase reviews returned `NEED_HUMAN` and `DENY`; the ALLOW fixture is synthetic. The Monday off-hours experiment is `SAFETY_ONLY`, with no predictive-alpha claim.

Start at [JUDGE.md](JUDGE.md) for the public product, [knowledge index](docs/knowledge/README.md) for settled findings, and [STATUS.md](STATUS.md) for operational state. Claims require dated source evidence. Distinguish token-price time from underlying-reference time, route from eligibility, API response success from simulated transaction success, and a policy decision from a signed transaction. Never put private keys in this repo or let a model approve its own spend.
