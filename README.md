# BNB tokenized stocks project

Working repository for a new Dyplux entry to [BNB Hack: Tokenized Stocks Edition](https://www.bnbchain.org/en/hackathons/tokenized-stocks). The product name and use case are still being selected. There is no application or deployed demo yet.

Research starts with one user task, current alternatives and the event's required Binance Web3 API integration. The provisional candidate is a pre-trade decision receipt comparing bStocks and Ondo for a fixed ticker and amount. It has no live quote or observed user task yet, so implementation has not begun. [Project brief](docs/00-project-brief.md), [verified event rules](docs/01-event-rules.md), [research scorecard](docs/research/idea-scorecard.md), [API map](docs/api-map.md), [current status](docs/status.md) and [decision log](docs/decisions/decision-log.md) record the evidence and stopping rule.

Bell is a separate CoinMarketCap hackathon project. This repository shares no code, credentials, data or deployment with Bell.
