# BNB tokenized stocks project

Working repository for a new Dyplux entry to [BNB Hack: Tokenized Stocks Edition](https://www.bnbchain.org/en/hackathons/tokenized-stocks). The product name and use case are still being selected. There is no application or deployed demo yet.

Research starts with one user task, current alternatives and the event's required Binance Web3 API integration. The original pre-trade comparison candidate was set aside after the founder identified its overlap with Bell and incumbent purchase flows. The current research test asks whether an eligible stablecoin holder can act on a cited company event through a real, amount-specific BNB Chain spot quote while their stock venue is closed. [The off-hours reset](docs/research/2026-10-01-off-hours-reset.md) and [economic edge and Agent Studio map](docs/research/2026-10-01-economic-edge-and-agent-studio.md) explain the candidate, competitors, cost test and disproof conditions. There is no observed user task, live Binance quote or approved implementation yet. [Project brief](docs/00-project-brief.md), [verified event rules](docs/01-event-rules.md), [API map](docs/api-map.md), [current status](docs/status.md) and [decision log](docs/decisions/decision-log.md) record the evidence and stopping rule.

Bell is a separate CoinMarketCap hackathon project. This repository shares no code, credentials, data or deployment with Bell.
