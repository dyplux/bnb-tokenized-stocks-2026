## Product gate

The 5 USDC route-state distinctions are measured and useful as Developer Experience evidence. They aren't enough to claim a separate purchase product. Yostocks already handles the broader guarded trading task, while PancakeSwap already handles multi-issuer discovery and quote routing. A single input-token variation is weak differentiation unless a permitted user can complete the exact task and demonstrably needs an explanation or action those surfaces don't give.

The current local interface only quotes NVDAB entry and inverse exit. The exact-budget Apple spec has no built interface, issuer-access verdict, full-cost quote or execution. Don't present it as finished. A product selection requires either an observed user failure and a recoverable next action or a different narrow task with stronger evidence. The five-minute tape can continue independently of that choice.
