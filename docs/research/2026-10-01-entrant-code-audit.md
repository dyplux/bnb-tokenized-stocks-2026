# Code audit of three event and execution substitutes

**Read:** 2026-10-01. **Scope:** selected public source files at fixed commits. No app was installed or run, and no claim about a live deployment follows from this read.

| Substitute | What the inspected code does | Boundary for our product decision |
|---|---|---|
| [Portir](https://github.com/yeheskieltame/portir/tree/761f0df0e04d9fa46f0007cf69c9558ecd434161) | Its [agent news check](https://github.com/yeheskieltame/portir/blob/761f0df0e04d9fa46f0007cf69c9558ecd434161/apps/portiragent/app/agent/src/portir/judge.ts) reads recent [Yahoo Finance and optional CoinDesk headlines](https://github.com/yeheskieltame/portir/blob/761f0df0e04d9fa46f0007cf69c9558ecd434161/apps/portiragent/app/agent/src/portir/news.ts). The model may hold a buy for a concrete near-term risk. Missing headlines, model failure or an unreadable answer let the rule-based guard proceed. Its [buy route](https://github.com/yeheskieltame/portir/blob/761f0df0e04d9fa46f0007cf69c9558ecd434161/apps/web/app/api/buy/route.ts) can return an unsigned route, but rejects an RFQ-only provider with HTTP 501 in the inspected branch. | It already covers a news-aware purchase and issuer comparison. A second headline summary or generic buy guard would overlap. Primary-source event timing and fail-closed handling of missing evidence could differ, but need a user task and live route before claiming value. |
| [PARALLAX](https://github.com/rishu4436/parallax/tree/45489f0b1baff1a4d94ee1eaf44c0365ee69c930) | Its [jobs code](https://github.com/rishu4436/parallax/blob/45489f0b1baff1a4d94ee1eaf44c0365ee69c930/packages/core/src/jobs.ts) requires a supplied earnings `printAt` for the flatten job. Its [quote route](https://github.com/rishu4436/parallax/blob/45489f0b1baff1a4d94ee1eaf44c0365ee69c930/apps/web/app/api/quote/route.ts) retrieves a Web3 quote book and plan. The [armed worker](https://github.com/rishu4436/parallax/blob/45489f0b1baff1a4d94ee1eaf44c0365ee69c930/apps/agent/src/agentRuntime.ts) evaluates basis, cross-rail and correlation conditions and has a broadcast path. | This is a serious execution and automation substitute. The inspected earnings job takes an event time as input; these files don't establish a primary issuer/filing watcher. We haven't audited every code path or run the app, so absence elsewhere is unproven. |
| [NightDesk](https://github.com/PhiBao/nightdesk/tree/c0379ea5486e372583dd52625803f005425bbb9e) | Its [guard](https://github.com/PhiBao/nightdesk/blob/c0379ea5486e372583dd52625803f005425bbb9e/src/lib/guard.ts) classifies user intent and session/price risk, with deterministic fallback. Its [execution layer](https://github.com/PhiBao/nightdesk/blob/c0379ea5486e372583dd52625803f005425bbb9e/src/lib/execution.ts) stores alerts and paper limit intents. Its [fill route](https://github.com/PhiBao/nightdesk/blob/c0379ea5486e372583dd52625803f005425bbb9e/src/app/api/fill/route.ts) can quote and simulate a pool swap, with optional capped live broadcast. | It already covers market-hour warnings, limits and a swap path. The inspected paths don't consume a company filing or issuer release as a trigger; the rest of the repo wasn't exhaustively audited. |

**Inference:** a timestamped company event connected to a fresh, size-specific Web3 route is less directly duplicated in these inspected paths than a quote guard, basket or market-hours alert. That remains a hypothesis. A Tuesday after-close event is also tradable in some incumbent extended-hours products, and source timing alone doesn't create a profit edge. An SEC filing can follow the first public company release. The founder has already rejected a Bell-like evidence receipt, so a future slice would need to change the user's executable choice rather than stop at provenance.

**Decision:** no product approval. The next discriminating evidence is one eligible person's off-hours stock task and one authorized signed Binance Web3 quote for that exact asset and amount. If that task is already solved in the incumbent flow, or the route is unavailable or uneconomic, don't build this candidate.
