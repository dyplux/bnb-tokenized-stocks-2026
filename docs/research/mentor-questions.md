## Priority question to send, if the founder chooses

> On 2 October, a signed BNB Chain quote for 1 NVDAB to USDT returned one LiquidMesh `SWAP` route. A fresh quote followed by `GET /swap` then returned an unsigned transaction payload, with quote `estimateGasFee=450000` matching `tx.gas=450000` and a separate `tx.gasPrice`. The endpoint reference still says RWA always RFQ. Is the SWAP route and transaction build expected for bStocks, and does `toTokenAmount` include vendor swap fees? Does `tradeFee` include approval gas, and which field, if any, represents expected net USDT after all route costs? We haven't signed, simulated or broadcast anything. A precise answer determines whether the estimated output can support a holder's same-cash comparison.

Do not send a wallet address, quote ID, key, secret or signed header with this question. Record any mentor reply with date and source before changing the product claim.

1. **bStock amount units in RFQ.** The [Trading API](https://web3.binance.com/en/dev-docs/catalog/web3-wallet/api/rest-api/trading-api) says `/quote.amount` is the sell token's smallest unit. [BEP-677](https://github.com/bnb-chain/BEPs/blob/master/BEPs/BEP-677.md) separates raw token units from multiplied UI units. For a bStock sell, should `/quote.amount`, `/approve-transaction.approveAmount`, and the signed RFQ amount all use canonical raw units? Which response fields, if any, are multiplied UI units? An incorrect answer could sell a different exposure than the screen shows.
2. **Eligibility and integration permission.** The [bStocks FAQ](https://www.binance.com/en-AE/support/faq/detail/f0c03cd6509a4085b4cce1636f16be38) says integrators must enforce geographic restrictions, mentions a public country eligibility endpoint and directs third parties to contact bStocks about integration. What is the exact endpoint and schema, which jurisdiction input is expected, what happens if the check is unavailable, and is a separate issuer arrangement required for a hackathon demo with a public trade action? Does a Binance Web3 quote or transaction response provide any definitive wallet restriction signal? A BNB address or successful Web3 quote doesn't establish eligibility.
3. **Small sell economics.** For SQQQB or QQQB on BNB Chain, does the current Binance Web3 RFQ support a sale worth roughly 1, 5 and 10 USDT, and where are route minimum, fees and expiry documented? The [Trading API](https://web3.binance.com/en/dev-docs/catalog/web3-wallet/api/rest-api/trading-api) says RWA RFQs bind to the wallet and expire after about 30 seconds, but the docs opened don't state a bStock-specific minimum. A published number is less useful than a wallet-bound read-only quote for a real amount; we will measure one once access is available.
4. **Reference provenance and quote fees.** The [RWA source audit](2026-10-01-reference-price-source-audit.md) found conflicting official descriptions of `referencePrice`. Which source and as-of time populate it for bStocks and Ondo, and may third-party apps display it as an independent equity quote? For each `/quote` route, which fields represent swap fee, gas and net receive, with what units and whether approval gas is included? Please distinguish SWAP and RFQ routes.
5. **Observed bStock SWAP route.** The [live quote](2026-10-02-first-live-binance-quote.md) returned `LiquidMesh` and `SWAP` for NVDAB, while the [endpoint reference](https://web3.binance.com/en/dev-docs/catalog/web3-wallet/api/rest-api/trading-api) says RWA always returns RFQ. A [later route-control read](2026-10-02-live-route-control.md) named Elfomofi, and a [read-only `/swap` build](2026-10-02-first-live-swap-build.md) returned an unsigned transaction payload. Confirm expected bStock SWAP support, which costs are included and whether approval gas is separate before describing this as an actionable sale.
