# Weekend MSTRB: quote works, generic agent already exists

**Checked:** 2026-10-03 UTC. This is a product gate for the earlier BTC-to-MSTRB candidate, not a change to the provisional NVDAB cash-choice build.

The [Saturday quote roundtrip](2026-10-03-mstrb-weekend-rfq-result.md) returned six successful Binance Web3 API quotes for MSTRB/USDT at 25, 100 and 500 USDT. The inverse estimates returned 99.75%, 99.69% and 99.65% of the starting amount before any additional execution costs. This proves a technical weekend quote path. The [ten-weekend Spot study](2026-10-01-weekend-crypto-equity-task.md) found BTC and MSTRB same-hour hourly-return correlation of 0.815, but BTC-to-next-hour MSTRB correlation of 0.074. The sample doesn't support a simple one-hour lag or profitable BTC trigger.

The [official Binance Agentic Wallet stock-trading guide](https://developers.binance.com/en/docs/products/agentic-wallet/use-cases/trading/stock-trading), modified 2026-10-02 and checked today, documents ticker resolution, trading-status check, amount-sized quote, buy, sell, order status and ongoing rules that watch stocks and act after earnings or news. It gives a quote-only prompt for 100 USDT and a confirmation step before a swap. This is documented capability; no end-to-end Agentic Wallet runtime task was observed here. It is still a strong first-party substitute for a generic weekend alert plus quote or conversational trade.

**Decision:** reject the generic BTC-move alert or buy rule as the next standalone product. Its measurable difference from the documented official flow is currently zero. Keep the closed-hours observation as research; re-open only if a user demonstrates a task the official flow fails at, and an amount-matched, cost-aware result changes that decision. No agent runtime, paid packet or auto-trading build is justified by these data. The [4 October D-033 checkpoint](../decisions/decision-log.md) for the separate NVDAB cash-choice hypothesis is unchanged.
