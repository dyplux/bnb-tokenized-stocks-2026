## Current decision

The old H1/H2/H3 scores were a subjective research ordering, not demand evidence. The founder challenged H1's similarity to Bell and then rejected blocked-exit recovery as the main direction. [D-006](decisions/decision-log.md) prioritized a public event after cash close; [D-008](decisions/decision-log.md) narrowed the trigger to BTC-linked MSTRB because SEC filings cannot arrive on weekends. Binance Spot trades bStocks around the clock, and yostocks already quotes and guards trades. [D-009](decisions/decision-log.md) therefore tests whether an exact, fresh BNB Chain route assessment changes a self-custody user's decision. No live Binance Web3 quote or observed user task exists, so no implementation is approved. The `referencePrice` field is derived from token price and cannot be used as an independent TradFi benchmark.

[D-007](decisions/decision-log.md) first proposed weekend access for an eligible person with BNB Chain funds. Binance's 24/7 Spot bStocks product weakens that access claim for eligible Binance users. The possible advantage is now execution control for a self-custody wallet, if a measured route difference survives actual bid/ask, slippage, fees and a valid exit. The paid Agent Studio idea has a 30-second RFQ-expiry problem and overlap with an existing entrant's seller; it remains optional until tested. Binance Agentic Wallet's current documentation already describes earnings/news watchers that can act under a user mandate. This is a published claim, not an observed run, and makes a generic event-to-order product insufficiently distinct.
