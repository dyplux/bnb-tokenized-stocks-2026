# Independent stock-reference clock is unavailable in the observed RWA fields

**Observed:** 2026-10-04 10:43:40 UTC. A signed, read-only `GET /api/v1/dex/market/rwa/price` returned HTTP 200, business code 0 and 40 BNB Chain stock-token rows. The [sanitized request fixture](../fixtures/2026-10-04-rwa-price-40-addresses-request.json) identifies the contracts and omits authentication headers. The [exact response body](../fixtures/2026-10-04-rwa-price-40-addresses-raw.json) has SHA-256 `03a10ed20b57a197a61fee28aa440d1c7262cd9afceb50cc8c6bea25bf2d9829`.

Each row has `tokenPrice`, `referencePrice` and `tokenPriceUpdatedAt`. None has a second as-of field for an independently observed underlying-equity quote. The top-level `timestamp` is response time. The [RWA Data documentation](https://web3.binance.com/en/dev-docs/catalog/web3-wallet/api/rest-api/rwa-data) describes `referencePrice` as an underlying reference but doesn't identify its upstream feed or as-of time. The separate [Binance Wallet Skills guide](https://github.com/binance/binance-skills-hub/blob/main/skills/binance-web3/binance-tokenized-securities-info/SKILL.md) gives a token-price divided by shares-multiplier formula. A later [40-row same-cycle check](../../../experiments/EXP-RWA-002/reference_formula_results.json) matched that arithmetic at reported precision. Neither the guide nor this match proves the signed field's upstream provenance or supplies an independent stock-reference clock.

Two [NVDA underlying-market response fixtures](2026-10-04-underlying-market-weekend-state.md) contained `marketData.referencePrice` and a top-level server timestamp, but no timestamp within `marketData`. Two [underlying-profile reads](../../../experiments/EXP-RWA-011/profile_probe.json) exposed ratio and protections, without a dated price or corporate-action field. These checks don't prove that no other API or external data source can provide a timed benchmark. They establish that the signed fields inspected here cannot measure its age.

**Reproduce:** with an authorized local API key in the ignored `.env`, run `python3 scripts/rwa_research.py once`, then inspect the latest `data/market_hours/YYYY-MM-DD.jsonl` rows and the corresponding raw price response in `data/market_hours/raw/`. This makes two signed read-only calls per cycle. The committed fixtures permit a no-key field and hash check: `shasum -a 256 docs/devex/fixtures/2026-10-04-rwa-price-40-addresses-raw.json`.

**Product handling:** store `token_price_updated_at` separately from `reference_price_updated_at=null`; set `reference_age_seconds=null` and `reference_age_status=UNKNOWN`. A policy requiring a fresh independent reference returns `NEED_HUMAN` unless an independently sourced, timestamped benchmark is supplied or that requirement is explicitly waived for the task. A fast-moving token price doesn't make the stock reference fresh.

**Suggested documentation/API improvement:** identify whether `referencePrice` is computed, separately sourced or provider-specific, and expose its venue, price type, as-of timestamp and market-session semantics where available. This would let builders distinguish per-share arithmetic from a timed traditional-equity reference.
