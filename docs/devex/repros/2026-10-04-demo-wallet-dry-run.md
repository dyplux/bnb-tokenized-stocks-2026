**Dry-run guard added after these first samples:** before requesting a build, the script now checks chain 56, source and destination token contracts, raw input amount and quote approval target against the intended 10 USDT action. Synthetic mismatch cases stop before the next call. A passing guard confirms field agreement in these API responses; it is not an allowlist or calldata security audit for signing.
