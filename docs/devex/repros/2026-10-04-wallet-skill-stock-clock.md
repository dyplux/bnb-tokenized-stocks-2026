# Public Wallet Skill stock value without its own clock

**Observed:** 2026-10-04 14:41:33 UTC. **Endpoint:** public Binance website `GET /bapi/defi/v2/public/wallet-direct/buw/wallet/market/token/rwa/dynamic/ai`, `chainId=56`, exact NVDAon contract `0xa9ee28c80f960b889dfbd1902055218cba016f75`. No API key, wallet, signature or order. Request follows the [official tokenized-securities Wallet Skill](https://github.com/binance/binance-skills-hub/blob/main/skills/binance-web3/binance-tokenized-securities-info/SKILL.md), API 5. The [bounded probe](../../../scripts/probe_wallet_skill_stock_info.py) and [full public response fixture](../fixtures/2026-10-04-wallet-skill-nvdaon-stock-info.json) reproduce the field inspection. Response SHA-256: `2f94a359f3b3785024d529523038367918593d7279231f15805341ddce14d8c1`.

HTTP 200/business `000000` returned `stockInfo.price=234.955`, `tokenInfo.price=235.327954823397903765` and `tokenInfo.sharesMultiplier=1.0017152487959898`. Dividing token price by multiplier gives `234.925`, 0.030 lower than the stock value. The provider Skill says the values come from different stock-feed and on-chain-oracle sources. The JSON contains no top-level timestamp and no timestamp/date field inside `stockInfo`. `statusInfo.marketStatus=offhours` and `openState=true` describe reported token/issuer trading state, not the US stock feed's as-of time.

**DevEx finding:** the public endpoint exposes a useful separate stock value but no independent update time, stock-feed venue, or data-rights statement in the inspected payload. Documenting `stockInfo.price` source, as-of timestamp and null behavior outside regular hours would let consumers distinguish a current benchmark from a held last value. We cannot assign `reference_age_seconds` from this response's arrival time or from `tokenInfo.price`.

This is a source-semantics and missing-timestamp finding, not a declared API failure. One Sunday response is not a reliability or market-hours study. The [source gate](../../research/2026-10-04-reference-clock-source-gate.md) keeps the stock clock unknown.
