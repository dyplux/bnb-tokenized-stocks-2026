## What we actually built and called

The current read-only safety screen uses signed **RWA Data** (`/tokens`, `/price`, `/underlying-market`) and **Trading** (`/aggregator/quote`) for one NVDA action. Its bStock branch also reads a BSC fixed-block multiplier. The Ondo branch uses the official public Binance Wallet Skill stock-info response, with no independent stock-feed timestamp. A separate **Transaction API** research path built five unsigned `SWAP` transactions and submitted four off-chain simulations by 15:20 UTC. These simulation API calls returned business code zero, while the predicted unfunded transactions failed. No transaction was signed or broadcast. The official Agentic Wallet runtime was not installed: its [install guide](https://developers.binance.com/en/docs/products/agentic-wallet/quickstart/install-agentic-wallet) requires a Binance account and MPC wallet, which the founder reports are unavailable. The public Wallet Skill read was integrated; don't describe it as an autonomous execution agent.

## Numbers and limits

At the 15:20 UTC snapshot, the log had **339 calls across 11 endpoint/method groups**. Signed `/tokens` had 93 business successes, 2,207.47 ms median and 3,746.25 ms nearest-rank p95 observed latency. Signed `/price` had 92 business successes and one HTTP 414. Signed `/quote` had 95 HTTP-200 responses: 84 business successes, two `40367` and nine `40374` rejections. All five unsigned `/swap` calls and four `/simulate` API calls returned business success. No HTTP 429 appears in this snapshot. These are mixed collector and exploratory calls, not a controlled benchmark. The [40-contract Sunday tape](../../experiments/EXP-RWA-010/results.json) tests token-price freshness only; its independent stock-reference age remains `UNKNOWN`. No observed spread is a realised profit or fill.

Both were corrected and retained in the [DevEx evidence summary](../devex/2026-10-04-evidence-summary.md).
